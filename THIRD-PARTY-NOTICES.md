## Unicode CLDR data in the `.ldml` writing-system files

The `.ldml` files under `fieldworks/WritingSystemStore/` of each witness derive from data of the Unicode Common
Locale Data Repository (CLDR), by way of the SIL Locale Data Repository and LibLCM.
