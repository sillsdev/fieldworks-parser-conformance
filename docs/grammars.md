# The grammars

Every test case directory under `languages/` and `edge-cases/` is listed here once, grouped by area, with
one line saying what its grammar and words exercise. Each test case has a `grammar.xml` and a
`words.yaml`; the larger ones also have a `README.md` with their rationale.

Every grammar here is one a real FieldWorks project can produce. A grammar that FieldWorks cannot
produce does not belong in the suite, however expressible it is in the XML; see
[what FieldWorks cannot produce](fieldworks-cannot-say.md#what-the-xml-can-say-but-fieldworks-cannot-so-we-do-not-test-it).

A test fails if a test case directory is missing from this page, listed twice, or listed here but gone.
The list has 188 test cases: 6 languages and 182 edge cases.

## Tier of every test case

The tier says how often a consumer should run a test case: **core** on every pull request, **regression** and **extended** on the full run. It is computed by `scripts/tiers.py` from data the suite holds, never authored, and never part of an id; `scripts/check_grammars_md.py` fails when this table is stale. A test case is core when it is a language profile, has a FieldWorks witness, or is one of the two smallest carriers of a behaviour label (a vocabulary label, constructs.txt or labels.tsv; fewest words first, then id). Otherwise it is regression when it has an exception in `status.yaml`, is the only test case citing some bug (the last detector of a bug is never removed, ADR 0008), or has 300 or more words, and extended when it has none of these.

## Which engines run which grammars

Engines need different amounts of phonology: what a grammar says about sounds, in segments, features and rules.

- **XAmple** works on letters: morphemes, allomorph strings, and string environments and natural classes written as lists of letters. FieldWorks' XAmple transforms write no phonological rules and no phonological features, so XAmple ignores both. It is a different algorithm (item-and-arrangement) from Hermit Crab (item-and-process, rules unapplied). It needs no phonology.
- **Hermit Crab** needs a complete phonology: every letter of every form and word is defined as a segment. An undefined letter makes the word unanalyzable, and FieldWorks' Hermit Crab loader drops allomorphs it cannot segment. It needs features only where a rule or natural class uses them.
- **PanGloss** runs grammars with no phonology, with incomplete phonology or with complete phonology. For incomplete phonology ("underdefined" in PanGloss's own terms) it supplies provisional definitions where FieldWorks' Hermit Crab loader drops material.

All 188 conformance and 16 stress grammars are Hermit Crab grammars, and PanGloss runs all of them. The suite has no grammar with incomplete phonology today; that is a gap.

### The XAmple subset

A grammar is in the XAmple subset when it has no phonological features and no phonological rules (`PhonologicalRule` or `MetathesisRule`). A grammar with rules but no features is not in it, because XAmple would ignore its rules. The subset is **66 conformance grammars and 6 stress grammars**. Each of their test case lines on this page carries the tag `[XAmple]`. `scripts/check_grammars_md.py` recomputes the subset from every `grammar.xml` and fails if this page or the README table disagrees.

`requires: []` is not the XAmple subset. It means no phonological rules, as [PROTOCOL.md](../PROTOCOL.md) section 5 defines it, so some `requires: []` grammars still have phonological features, and some subset grammars carry `requires: [morpher-settings]` because their `words.yaml` sets a `morpher:` block. Five grammars in the subset need `morpher-settings`; they are marked below.

Each is a dense, synthetic grammar (invented lexemes and segment inventories, no orthographic claim
about any real language) where ordinary words exercise several constructs at once, rather than a
one-mechanism probe. `edge-cases/` holds the things no shared grammar can host faithfully:
loader/XML-semantics probes, an `expect_crash` pin, a `budget_ms` pathological stress case, and
allomorphy/rewrite pins whose exact rule shape a naturalistic grammar wouldn't contain.

## The six languages

Whole-language grammars with a realistic lexicon and several interacting processes.

- `languages/metathesis-phase-isolation`: infixation, circumfixation, reduplication, metathesis and truncation, one demonstration per part of speech (26 words).

- `languages/templatic-root-modification`: stem names and templatic root modification, with epenthesis, prothesis, feeding and geminate rules (25 words).

## Alpha variables in environments

These families repeat one pattern across rewrite direction and environment side, so each is one test case of
cells (the first former member's id is kept; the others are in `docs/renames.tsv`). A cell's name says
what it fills: `bounded` or `unbounded` is whether the repeated stretch has a cap, `ltr` or `rtl` is the rewrite
direction, and `left` or `right` is the side that holds the environment. `plain` means the environment holds no
repeated stretch, and `zero` means the repeated stretch may occur zero times. Each cell has 16 or 17 words over
a small vowel set, spelled with its own letters. Each bullet says what the grammar holds.

### Nullable environment with disagreeing alpha values

- `edge-cases/nullable-disagree-bounded-ltr-left`: a back and round disagreement over the whole four-vowel class with a nullable stretch in the environment, in nine cells that differ in the stretch's bound (an optional segment, or any length including none), the rewrite's direction and the environment's side, plus one cell with no environment.

In each cell the nullable stretch in the environment must still allow the rewrite at the word edge, so `ia` is the one surface word.

### Partial explicit class with disagreeing alpha values

- `edge-cases/partial-class-disagree-bounded-ltr-left`: a disagreement over an explicit vowel class that omits some of the four vowels, in six cells that differ in the class's members, the stretch's bound, the rewrite's direction and the environment's side.

Each cell uses an explicit vowel class that omits at least one of the four vowels, so the engine accepts only `ia` of the 16 words.

### Ambiguous disagreement

- `edge-cases/ambiguous-disagree-feature-class-bounded-rtl`: 4 cells in one grammar, each with its own rules and words. `bounded-rtl`: an optional segment, right-to-left application, environment on the right; `unbounded-ltr`: a stretch of any length, including none, left-to-right application, environment on the right; `mixed-plus`: no environment at all, left-to-right application; `repeated-minus`: one segment, left-to-right application, environment on the left.

Each combines a minus alpha on a complete class with an agreeing occurrence on a partial class, or on a
feature-defined class, in a bounded or unbounded environment.

### Overridden alpha

- `edge-cases/overridden-alpha-bounded-ltr-left`: a neutralisation of a feature that an alpha variable also governs, in four cells that differ in the stretch's size (1 to 2, 1 or more, or none), and the rewrite's direction.

In each cell the engine requires `ii` from `iu`.

### Quantified alpha agreement

- `edge-cases/quantified-alpha-bounded-ltr-left`: a repeated segment in the environment whose alpha value must agree across the repetition, in twelve cells that differ in the repetition's bound (exactly 2, 2 or more, up to 2 or any number including none), the rewrite's direction and the environment's side.

In the `zero` cells the stretch may also be empty.

## Stress grammars

The 16 grammars under `stress/` (at the repository root, beside `edge-cases/`) are timing
probes for the analysis pass, not test cases, and no coverage ledger counts them. They follow the same rule: only
grammars a FieldWorks project can produce. All 16 are claims read from the loader, and
none has a FieldWorks witness yet (issue #1). Their expected output is a parity check against an engine, not a
conformance claim. [stress/README.md](../stress/README.md) says what each really exercises and which
sillsdev/machine optimization it was built for; `scripts/check_grammars_md.py` fails if this list and that table
differ from the directory.
